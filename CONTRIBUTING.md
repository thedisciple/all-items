# Contributing

Thanks for helping improve All Items. Please open an issue before substantial changes so the scope and product direction can be discussed. Keep changes focused, preserve privacy by default, and do not include real personal inventory data or credentials in issues, fixtures, or commits.

Use English for code and public documentation; the product interface is Russian. Add or update tests for changed behavior, and run typecheck, lint, tests, and the production build before submitting a pull request. Use concise conventional commit messages. There is no CLA or copyright assignment requirement.
