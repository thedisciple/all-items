# Roadmap

## M0 — Foundation and first working vertical slice

- [x] Next.js, TypeScript, Tailwind, SQLite, and Drizzle foundation
- [x] Local workspace and additive initial migration
- [x] Russian responsive inventory page and item creation
- [x] Persistence across application restarts
- [x] Focused validation tests and project documentation

## M1 — Inventory management

- [x] Full item CRUD and sequential inventory numbers
- [x] Stock entries, quantities, and multiple locations
- [x] Tracking modes, search, filters, sorting, and private sale intent

## M2 — Media and collections

- [ ] Validated private local images and thumbnails
- [ ] Collections and responsive item cards/list
- [ ] Unidentified object workflow

## M3 — Portability and recovery

- [ ] Structured import/export with image data
- [ ] Backup and restore guidance
- [ ] Flexible item attributes and integrity checks

## M4 — Quality and release

- [ ] Mobile UX refinement and security review
- [ ] Optional authenticated LAN access, only if secure implementation is complete
- [ ] CI, synthetic-data screenshots, and release preparation

AI, marketplace, sharing, and synchronization remain future directions and are not part of M0.
