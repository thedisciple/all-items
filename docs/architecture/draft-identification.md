# Accepted-photo creation review (M5C)

Enable the same server-controlled local Ollama configuration as M5A (default off, off in HTTPS proxy mode). In Add Item finish a photo crop, choose Identify from photo, review current/proposed fields, then Use selected in form. One accepted primary image is used, not a pending crop, source original or thumbnail. Nothing infers automatically. Save Item remains the existing single creation/staging/finalization/receipt flow. No model, GPU or network is required for manual inventory.

Browser preflight and canvas re-encode at 1024px/512KiB precede transfer. The raw-image endpoint authenticates, verifies exact Origin and inventory, validates locale/request UUID and acquires the same private lock/SQLite quotas as saved analysis before streaming/decoding. A streaming 512KiB limit, MIME/magic/type checks, 1024-side/1MP cap and metadata-free Sharp re-encode protect the provider. The request has a 95-second ceiling, with the existing provider deadline too. No client model/destination/path, context, notes or stock is accepted. Aborts cancel reading/provider requests best effort; they do not prove instantaneous GPU cancellation.

Inference changes only operational throttle rows and an ephemeral private lock, never items, numbers, media, stages, receipts or proposals. Apply modifies only name/brand/model/description and additive canonical categories in the existing local draft. Those accepted fields persist through ordinary draft recovery; proposal/provenance do not. Notes, marking, status, tracking, price, stock, gallery and receipt identity are untouched. AI transfer is disabled after a creation attempt until explicit recovery/new operation.

Request generation plus immutable accepted File identity/photo ID bind results to the dialog. Close, navigation, restore/reset, recrop/replacement/primary change and save invalidate/abort. Late results cannot apply. Changed form fields lose selection; apply also compares synchronously to the latest values and requires explicit reselection of changed fields. No proposal is persisted or exported. Unknown/error/cancel preserves manual creation.

SourceReview captures a revision when opening. Active input survives background refresh with that revision. Stale responses refresh saved props without rebinding edits, and offer Restart. Opening a new review uses current saved brand/model/citation/query and clears optional description and confirmation. Refresh transition blocks premature reopen after a successful mutation.

Synthetic tests use the existing test-only Ollama preload; there is no production fake mode. Existing creation/recovery/retry and saved AI/source regressions remain gates. No real Ollama smoke, photographs, devices, public exposure or migrations are required/performed. M4E isolated-server loss and cancellation ECONNRESET, security/physical/network/Telegram/reboot acceptance remain open, without global exception suppression.
