# Owner-attested source evidence

The saved-item source panel works without AI/photos/network. The owner copies/edits brand+model lookup text, reads an official source in their own browser, then explicitly confirms exact identity and a citation. Original marking is displayed separately and excluded from default lookup. Family/alias ambiguity should remain unknown or user-confirmed. URL shape never proves publisher identity. Links are HTTPS, credential-free, escaped, explicit and no-referrer/noopener; there is no server/client fetch, preview, scraping or automatic search.

One JSON citation lives on items.source_evidence. Confirmation stores brand/model/marking snapshot and server time with optional selected description; unrelated rows/fields remain untouched. Removal downgrades documented status. Database identity trigger removes evidence and downgrades to user-confirmed on brand/model/marking changes, including AI and ordinary edits. Unrelated updates preserve it; explicit status downgrade clears evidence. Generic creation/edit cannot newly grant source_verified. Historical source_verified without citation stays legacy and is labelled separately. Filters retain enum compatibility; that enum alone does not imply documentation.

Migration 0016 is additive. Only isolated fixtures are migrated during development; populated installation migrations require verified backup and isolated restore first. ZIP7 and installation backups preserve citations; old revisions import null evidence and retain historical status. No identity/account/path/secret or AI draft is added to portable data. Lost-response retries fail stale revision and require reload/inspection. Panel errors/cancel retain inputs. Normal editor merges refreshed saved fields only when its corresponding local value was untouched.

Stacked on unmerged M5A. After dependencies merge, review origin/main and retarget without rewriting published history. M4E runtime loss/ECONNRESET, independent security, phones/networks, Telegram and reboot remain open. No actual Ollama or live beta is needed/exercised by this feature.
