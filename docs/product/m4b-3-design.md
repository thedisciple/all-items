# M4B.3 interaction notes

The existing responsive inventory cards and toolbar remain the foundation. One labelled, keyboard-accessible View options control selects locally stored per-inventory details; item identity and inventory number remain visible. Added time is opt-in in the list and concise in the detail page. These are interaction choices grounded in [design principles](ux-principles.md), [interaction patterns](interaction-patterns.md) and the [manifesto](design-manifesto.md), not a claim of physical-device validation.

The Edge layout gate exercises five locales and narrow viewports with synthetic content. Device camera, touch, actual browser zoom, assistive technology and real-world task acceptance remain manual gates in the [device runbook](../architecture/m4b-3-device-pilot.md). Preferences do not travel in portable archives.
